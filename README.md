# wsociety-bot-scanner
wsociety-bot-scanner é um agente autônomo em Python inspirado na cultura hacker. Focado em auditoria e segurança, o bot varre projetos Java locais, higieniza códigos removendo credenciais sensíveis por regex e usa a API da OpenAI para detectar falhas críticas como SQL Injection e violações SOLID, gerando um relatório técnico no terminal.
